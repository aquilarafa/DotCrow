# 0001. Núcleo escrito em Rust

- **Status:** aceita
- **Data:** 2026-10-19

## Contexto

O núcleo do DotCrow guarda chaves de API, faz criptografia e vai executar ações no computador do dono. Erros de memória nesse tipo de código viram falhas de segurança. Também precisamos de binários pequenos para Windows, macOS e Linux, sem exigir que a pessoa instale um runtime.

## Decisão

O núcleo (cofre, criptografia, roteador, agentes, Ninho e CLI) é escrito em Rust, num workspace com um crate por responsabilidade. `unsafe` é proibido no workspace.

## Alternativas consideradas

- **Python:** ótimo ecossistema de IA, mas distribuir com segurança e sem runtime é difícil, e não temos garantias de memória.
- **TypeScript/Node:** rápido para prototipar, mas o mesmo problema de distribuição e uma superfície grande de dependências.
- **Go:** boa opção; perdemos para Rust pelo ecossistema de criptografia pós-quântica (RustCrypto) e pelo controle de apagar segredos da memória.

## Consequências

- A curva de entrada é maior para quem não conhece Rust. Compensamos com issues bem descritas e documentação em português.
- Integrações que só existem em outras linguagens podem entrar como ferramentas externas chamadas pelo Ninho, sem tocar o núcleo.
